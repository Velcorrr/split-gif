BEHIND THE SWITCH

Two readers.
A different result.

This experiment uses a quirk in how GIFs are decoded. It works best in Chromium browsers, and isn’t guaranteed in every viewer.

01 /

Pick both sides. The first animation is the intended chat preview. The second follows it when the original is opened in a compatible browser.

02 /

A tiny break between them. A malformed transition can make a strict image processor stop after the first GIF. A tolerant browser can continue into the second.

03 /

Download and try it. Send the downloaded file as a GIF attachment. Compare its chat preview with the original attachment opened in your browser. Re-encoding may remove the effect.
