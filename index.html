A NOTE ON THE EXPERIMENT
Same bytes.
Different eyes.
Two decoders can read the same file differently. This is a format experiment, not a guarantee that every app will see the same thing.
I.
The first impression. Choose an animated intro, or a still cover encoded as exactly one frame. Images are fitted to the reveal’s canvas.
II.
The break. A deliberately malformed transition can stop a strict image processor after the intro. A tolerant Chromium browser can continue into the reveal.
III.
The reveal. Download the file and compare Discord’s preview with the original attachment. A very short cover may still flash. Re-encoding can remove the effect.
